开启后手机和电脑都填同一套（同一个令牌 + 同一个同步密码），数据自动对齐。
数据存在一个私有的 GitHub Gist 里，并用下面的「同步密码」AES 加密，没有密码谁也读不了（包括 GitHub）。
密码忘了无法恢复，建议先导出一份备份再开。
